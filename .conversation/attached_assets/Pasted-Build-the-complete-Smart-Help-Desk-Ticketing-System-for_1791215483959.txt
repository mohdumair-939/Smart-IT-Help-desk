Build the complete **“Smart Help Desk Ticketing System for IT Services”** from scratch and take it through **development, testing, deployment, and publishing**.

Act as the **Lead Full-Stack + AI/RAG + DevOps Engineer**.

### Tech Stack

* Frontend: React + TypeScript + Tailwind
* Backend: Python + FastAPI
* Database: PostgreSQL
* ORM: SQLAlchemy + Alembic
* Authentication: JWT + RBAC
* AI: Gemini/OpenAI API
* RAG: LangChain + ChromaDB
* Storage: Supabase Storage or suitable object storage
* Git/GitHub for version control
* Deploy the complete application publicly using the most suitable Replit deployment option.

### Core Features

**1. Authentication & RBAC**

* Employee
* Support Engineer
* Admin
* Secure password hashing and JWT authentication.

**2. Help Desk**

* Create/view/update tickets
* Ticket number
* Category, priority, status
* Department and engineer assignment
* Comments
* Attachments
* Resolution
* Ticket activity/audit history

**3. Knowledge Base**

* Admin/engineer document upload
* PDF/TXT/DOCX/Markdown support where practical
* Document processing and chunking
* Embeddings
* Vector storage
* Search and retrieval

**4. RAG AI Assistant**

* Understand the ticket
* Retrieve relevant knowledge-base content
* Generate grounded troubleshooting/resolution suggestions
* Display the source documents/citations
* Do not hallucinate or fabricate sources
* If knowledge is insufficient, clearly state that and recommend escalation.

**5. Dashboard**

* Open/resolved/closed tickets
* Priority/category/department statistics
* Engineer workload
* Recent activity
* Use real database data, not hard-coded values.

### Architecture

Use a clean, maintainable architecture:

```text
React
  ↓
FastAPI
  ↓
Services / Repositories
  ↓
PostgreSQL

Knowledge Base
  ↓
Chunking → Embeddings → ChromaDB
  ↓
Retriever → LLM → Grounded Response + Sources
```

Keep frontend, backend, database, and AI logic properly separated.

### Development Process

Do NOT build everything blindly in one step.

Work incrementally:

1. Inspect existing repository.
2. Set up architecture.
3. Database + migrations.
4. Authentication/RBAC.
5. Ticket management.
6. Comments/attachments/audit logs.
7. Knowledge Base.
8. RAG pipeline.
9. AI resolution assistant.
10. Dashboard.
11. Testing/security.
12. Deployment.
13. End-to-end production testing.
14. Documentation.

After every major milestone, run tests and fix errors before continuing.
